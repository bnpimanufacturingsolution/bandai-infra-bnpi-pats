# Public Surface Update Prompt

## Purpose

Draft and review public/user-facing communication for meaningful shipped behavior or release changes.

## How to Use

Use after implementation or during release planning when a change may need release notes, help docs, notices, onboarding copy, support articles, app store notes, or internal user announcements.

## Rules

- Public copy should describe user outcomes, not internal implementation details.
- Drafts must remain unpublished unless explicit approval is given.
- Public copy must match shipped truth.
- Human approval is required when the message affects customers, legal/compliance posture, pricing, permissions, safety, or trust.

## Output Format

```md
Audience:
Surfaces reviewed:
Draft copy:
Canonical terminology checked:
Approval required:
Publication status:
Known risks:
```
