# WWG Reports

Status: ACTIVE

This folder contains generated WWG reports, handoffs, validation outputs, context refresh reports, readiness reviews, and candidate-only runtime skill metadata.

Reports are evidence and handoff artifacts. Reports do not override canonical wiki truth in `.wwg/wiki/`.

## Common Reports

- `wwg-agent-handoff.md`: generic agent handoff.
- `wwg-handoff-to-codex.md`: Codex compatibility handoff.
- `wwg-validate-report.md`: latest validation result.
- `wwg-refresh-context-report.md`: latest generated context refresh result.
- `wwg-generate-governance-report.md`: latest governance generation result.
- `wwg-audit-report.md`: audit result.
- `wwg-infra-check-report.md`: infrastructure readiness result.
- `runtime-skill-candidates.md`: candidate-only runtime skill suggestions.

## Maintenance Rule

When a report conflicts with `.wwg/wiki/project-truth.md`, update canonical truth or regenerate the stale report. Do not treat a report as accepted product truth by itself.
