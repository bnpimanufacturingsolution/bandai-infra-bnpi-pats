# MVP Phases — Device Enrollment and Reconciliation

## Phase 1 — Read-only truth

Preflight, source/target selection, device-user discovery, sync preview, and evidence capture. No writes.

## Phase 2 — Human resolution

Filterable review table, exact-match/unmatched/conflict states, employee linking, field-level merge choices, and Apply guard.

## Phase 3 — Controlled execution

Preview revalidation, async job progress, cancel, partial-result semantics, and audit summary.

## Phase 4 — Verification

Re-read source/target/BNPI PATS state, show divergence, safe retry, and downloadable evidence.

## Phase 5 — Runtime promotion

Prove local → LAN VM → GitOps/K3s → public target. This phase is not complete from local browser proof alone.
