# PATS Line Setup & Station Configuration

The Line Setup workspace allows plant supervisors and industrial engineers to configure workstations, production lines, and operator assignments.

---

## 1. Station Management

Each Station represents a physical machine, booth, or assembly workbench on the factory floor:
- **Station ID**: Unique physical code (e.g., `STN-INJ-04`, `STN-DECO-SP02`).
- **Assigned Sub-Stage**: The specific operation executed at this station (e.g., Molding, Tampo Printing, Assembly).
- **Physical Line**: The production line grouping (e.g., "Line 1 - Gundam Main", "Line 3 - Figures").
- **Hardware Integration**: Paired USB/Bluetooth barcode/QR scanner and label printer.

---

## 2. Shift & Operator Assignment

- **Operator Check-in**: Operators scan their badge at the station to log active duty.
- **Process Instructions**: Stations display digital Standard Operating Procedures (SOPs), part schematics, and color references for the active batch.
