# Evidence Standards

Defines acceptable evidence quality for WWG decisions.

## Evidence Levels

- `confirmed`: direct code, config, or verified runtime behavior.
- `likely`: consistent docs and implementation signals.
- `inferred`: plausible but unconfirmed from indirect signals.

## Requirements

- High-risk claims require `confirmed` evidence.
- Inferred claims must include explicit uncertainty labels.
- Conflicts must be recorded before close-out.
