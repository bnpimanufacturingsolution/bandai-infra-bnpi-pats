# Canonical Context Policy

Defines canonical context sources for adopted projects.

## Canonical Order

1. `.wwg/wiki/project-truth.md`
2. `.wwg/wiki/terminology.md`
3. `.wwg/wiki/principles/README.md`
4. `.wwg/workspace/current-task.md`
5. `.wwg/governance/drift-guard.md`

## Rules

- Prefer canonical artifacts over generated summaries when conflicts exist.
- Mark uncertain reality as `NEEDS_CONFIRMATION`, `CONFLICTING`, or `STALE`.
- Do not silently overwrite Project Truth.
