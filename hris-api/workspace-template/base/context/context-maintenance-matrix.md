# Context Maintenance Matrix

## Coverage Matrix

| Change Type | Workspace/Governance Action |
|---|---|
| Major feature | Update current task, relevant context, and truth sync notes |
| Bug fix with canonical behavior impact | Record regression intent and update guardrail links |
| Architecture/runtime change | Update architecture/runtime context artifacts |
| Data model/persistence change | Update migration context and persistence notes |
| Security/permissions change | Update security/governance context and approvals |
| UI/UX/design system change | Update UX context and affected guidance |
| Public surface update | Update public surface review and linked artifacts |
| Public discovery/SEO/GEO change | Update public discovery context and checks |
| Public content/release-note change | Update changelog context and release notes mapping |
| Cloud/deployment/infrastructure change | Update runtime/infrastructure context and readiness |
| Production monitoring/read-only audit | Update monitoring evidence references |
| Regression guardrail/signoff learning | Update regression context and signoff references |
| Agent behavior/prompt/skill change | Update AGENTS and skill/workspace context |
| Profile-specific domain rule change | Update domain context and profile references |
| Template-vs-instance change | Update boundary context and migration notes |
| Workspace generation | Regenerate workspace outputs and reports |
| Governance generation | Regenerate governance outputs and reports |
| Context refresh | Refresh project/architecture/domain/governance context |
| Skill refresh | Refresh skill index and recommendation context |
| Dogfood/self-maintenance change | Update self-maintenance workflow and reports |
